# Code of Conduct

This project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
as its code of conduct. The canonical text lives at the link above. It
covers the standards we expect, our responsibilities as maintainers,
scope, and enforcement guidelines.

Please read it before contributing.

## Reporting

If you experience or witness behaviour that violates the Contributor
Covenant in this project's spaces (issues, pull requests, discussions,
or any other channel run by the project), please report it privately
through this repository's security advisories
(<https://github.com/dataGriff/slopstopper-snyk-safe/security/advisories/new>),
which reach only the maintainers.

Reports are received privately by the maintainers. We will respond
within 5 working days, and follow the
[enforcement ladder](https://www.contributor-covenant.org/version/2/1/code_of_conduct/#enforcement-guidelines)
defined in the Contributor Covenant.

## Scope

This Code of Conduct applies to all project spaces (the GitHub
repository, its issues, pull requests and discussions, and any public
channels run on behalf of the project) and to project members
representing SlopStopper in public spaces.
